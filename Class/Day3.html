TABLETAGS


Tag Name Description When to use
table Defines a table in HTML. Use when you want to represent tabular data.
caption Defines a caption for a table. Use to provide a title or description for a table. This tag must be placed immediately after the table tag.
th Defines a header cell in a table. Use inside tr tag to define header cells in a table. It automatically bolds and centers the content.
tr Defines a row in a table. Use to group content in a row inside the table. It can contain th tag or td tag elements.
td Defines a standard cell in a table. Use inside a tr tag to define a data cell that holds content in the table.
thead Groups the header content in a table. Use to group the header rows (tr tag elements) in the table, usually containing th tag cells.
tbody Groups the body content in a table. Use to group the body rows (tr tag elements) in a table, usually containing td tag cells.
tfoot Groups the footer content in a table. Use to group the footer rows (tr tag elements) in a table. This is typically used for summaries or totals.
