                                                HTML

Introduction

HTML is the standard language used to create and structure content on the web. It is a markup language that uses elements (tags) to define the structure, content, and layout of a webpage.

WHERE ARE HTML FILES EXECUTED?

HTML files are executed in web browsers. The browser reads the HTML file, interprets its tags, and displays the content as a structured webpage.

SEMANTIC vs NON-SEMANTIC TAGS

1.Semantic Tags:
Semantic tags clearly describe the meaning of the content they contain. These tags make the HTML code more readable and help browsers understand the structure of the webpage.
2. Non-Semantic Tags:
Non-semantic tags do not describe the content they contain. They are used purely for structural purposes and do not provide any meaning about the content.
