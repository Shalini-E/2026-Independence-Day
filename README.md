🇮🇳 The Freedom Scroll – India's Journey From Struggle To Glory

Overview

The Freedom Scroll is a storytelling-based Independence Day web project that presents India's inspiring journey from colonial rule to becoming a modern global nation.

The website takes visitors through significant milestones of India's freedom struggle, highlights legendary freedom fighters, and showcases India's achievements after independence.

Built using HTML5 and CSS3, the project focuses on semantic structure, historical storytelling, and a clean visual presentation.


Features

📜 Historical Timeline

The website covers major events in India's independence movement:

- Spark of Rebellion (1857)
- Jallianwala Bagh (1919)
- Dandi March (1930)
- Quit India Movement (1942)
- Independence Day (1947)

🦸 Freedom Heroes Section

Highlights inspiring leaders including:

- Mahatma Gandhi
- Bhagat Singh
- Netaji Subhas Chandra Bose
- Rani Lakshmi Bai
- Sardar Vallabhbhai Patel
- Subramania Bharathiyar

🚀 India Rising

Showcases India's progress in:

- Space Exploration
- Chandrayaan Missions
- ISRO Achievements
- Digital India
- UPI Revolution
- Startup Ecosystem
- Innovation & Technology

🇮🇳 The Journey Continues

A motivational ending that reminds every citizen of their role in building the future of India.
